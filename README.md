# نظام إدارة الاستثمارات والموظفين

مشروع برمجى متكامل يجمع بين واجهات المستخدم الأمامية والبرمجة الخلفية لإدارة الموظفين والعمليات الحسابية الخاصة بالاستثمارات.

## 📂 ملفات المشروع الأساسية

*   `الاستثمارات.html`: الواجهة المخصصة لعرض وإدارة البيانات المالية والاستثمارية.
*   `test_accounting.py`: الأكواد البرمجية المخصصة لاختبار الحسابات والميزانية.
*   `test_meta_hub.py`: ملف اختبار وفحص البيانات الوصفية الخاصة بالمشروع.

## 🛠️ التقنيات المستخدمة

*   **HTML5:** لبناء وتصميم صفحات الموقع.
*   **Python:** لكتابة واختبار العمليات البرمجية الخلفية.
