## 📦 تثبيت المتطلبات

### الخطوة 1: نسخ المستودع

```bash
# استنساخ المستودع
git clone https://github.com/mytamwt3-hub/Am-hup.git
cd Am-hup
```

### الخطوة 2: إنشاء بيئة افتراضية (Virtual Environment)

```bash
# على Windows
python -m venv venv
venv\Scripts\activate

# على macOS/Linux
python3 -m venv venv
source venv/bin/activate
```

### الخطوة 3: تثبيت المكتبات المطلوبة

```bash
# تثبيت Flask (إذا كان مستخدماً)
pip install flask

# تثبيت مكتبات Python الأساسية
pip install decimal
pip install json
pip install sqlite3
pip install datetime

# تثبيت المكتبات الاختيارية (للميزات المتقدمة)
pip install requests       # للاتصال بـ APIs
pip install python-dotenv   # لإدارة متغيرات البيئة
pip install pytest         # لتشغيل الاختبارات
```

## ▶️ تشغيل السيرفر الرئيسي

### الطريقة 1: تشغيل الخادم عبر Python المباشر

```bash
# تشغيل خادم Flask
python backend_server.py

# أو على macOS/Linux
python3 backend_server.py
```

**الإخراج المتوقع:**
```
 * Serving Flask app 'backend_server'
 * Debug mode: on
 * Running on http://127.0.0.1:5000
 * Press CTRL+C to quit
```

### الطريقة 2: تشغيل مع خيارات متقدمة

```bash
# تشغيل مع Host معين والمنفذ
python backend_server.py --host=0.0.0.0 --port=8000

# تشغيل في وضع الإنتاج (Production)
export FLASK_ENV=production
python backend_server.py

# تشغيل مع Debugging مفصل
export FLASK_DEBUG=1
python backend_server.py
```

### الطريقة 3: تشغيل المحاسبة والاستثمارات

```bash
# تشغيل نظام المحاسبة الأساسي
python accounting_core.py

# تشغيل نظام الاستثمارات
python investments.py
```

## 🛠️ استكشاف الأخطاء

### مشكلة: الخادم لا يبدأ

```bash
# الحل 1: تحقق من منفذ الاتصال
lsof -i :5000  # على macOS/Linux
netstat -ano | findstr :5000  # على Windows

# الحل 2: غير المنفذ
python backend_server.py --port=8000

# الحل 3: امسح ملفات الكاش
rm -rf __pycache__
rm -rf .pytest_cache
```

### مشكلة: خطأ في قاعدة البيانات

```bash
# الحل 1: حذف قاعدة البيانات القديمة وأعد إنشاءها
rm metahub.db
python backend_server.py  # سيعيد إنشاء قاعدة البيانات

# الحل 2: تحقق من صلاحيات الملفات
chmod 755 .
chmod 644 *.db
```

### مشكلة: الاختبارات تفشل

```bash
# الحل 1: تحقق من تثبيت pytest
pip install pytest --upgrade

# الحل 2: امسح الملفات المؤقتة
pytest --cache-clear

# الحل 3: شغل الاختبارات مع Verbose
pytest test_accounting.py -vv --tb=long
```
