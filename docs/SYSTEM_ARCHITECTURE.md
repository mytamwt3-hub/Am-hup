## 🎯 الأنظمة الفرعية الرئيسية

### 1. نظام المحاسبة الذكي (Smart Accounting System)

**الملفات**:
- `accounting_core.py` - النواة الأساسية للعمليات المحاسبية
- `chart_of_accounts.py` - دليل الحسابات
- `admin.html` - لوحة التحكم المحاسبية

**المسؤوليات**:
```
┌─ إدارة الحسابات (Accounts Management) ─┐
│ ├── إنشاء حسابات جديدة                  │
│ ├── تصنيف الحسابات (أصول، خصوم، إيرادات) │
│ └── إدارة أرصدة الحسابات                │
└─────────────────────────────────────┘

┌─ القيود المحاسبية (Journal Entries) ─┐
│ ├── تسجيل المبيعات                    │
│ ├── تسجيل المصروفات                    │
│ ├── تسجيل التحويلات                    │
│ └── موازنة القيود                      │
└────────────────────────────────────┘

┌─ التقارير المالية (Financial Reports) ┐
│ ├── كشف الحساب                        │
│ ├── قائمة الدخل                       │
│ ├── الميزانية العمومية                │
│ └── تقارير ضريبية                     │
└─────────────────────────────────────┘
```

**تدفق البيانات**:
```
مبيعة منتج → حساب المبيعات (debit) + حساب العميل (credit)
           ↓
         عمولة منصة 5%
           ↓
حساب عمولات المنصة (417) ← عمولة منصة
           ↓
تحديث المخزون والأرصدة
```

**المعادلات**:
```
الأصول = الخصوم + حقوق الملكية
إجمالي المبيعات = Σ(السعر × الكمية)
صافي الربح = الإيرادات - المصروفات
معدل العائد = الربح / رأس المال × 100
```

### 2. نظام إدارة الاستثمارات (Investment Management System)

**الملفات**:
- `investments.py` - محرك الاستثمارات
- `investments.html` - واجهة إدارة الاستثمارات
- `backend_server.py` - خادم المعالجة

**المسؤوليات**:
```
┌─ تسجيل الاستثمارات ─────────────────┐
│ ├── إنشاء محفظة استثمارية جديدة       │
│ ├── تحديد شروط الاستثمار              │
│ ├── توثيق الاتفاقيات                  │
│ └── قفل رأس المال                     │
└──────────────────────────────────┘

┌─ تتبع الأداء ─────────────────────┐
│ ├── حساب العوائد المحققة             │
│ ├── حساب العوائد المعلقة             │
│ ├── معدل العائد السنوي (ROI)        │
│ └── مقارنة الأداء                    │
└──────────────────────────────────┘

┌─ توزيع الأرباح ──────────────────┐
│ ├── حساب الربح المكتسب             │
│ ├── خصم المصروفات الإدارية         │
│ ├── توزيع الربح على المستثمرين    │
│ └── تحديث أرصدة المحافظ           │
└──────────────────────────────────┘
```

**حسابات الاستثمار**:
```
حساب 116: محفظة التاجر (Merchant Wallet)
├─ رصيد أولي = رأس مال الاستثمار
├─ + الأرباح المحققة
├─ - المصروفات
└─ = الرصيد الحالي

مثال على عملية:
1. المستثمر يودع 10,000 ريال
   debit: INV_HOLD (حساب الحجز المؤقت)
   credit: Customer Account (حساب العميل)

2. عند البيع:
   - تحديد الكمية المباعة من المحفظة
   - حساب الربح = السعر_الحالي - السعر_الأصلي
   - تخصيص العمولة (5%)
   - تحديث الرصيد المتاح
```

**دورة حياة الاستثمار**:
```
1. الإنشاء (Creation)
   └─ حالة: ACTIVE

2. التراكم (Accumulation)
   ├─ المبيعات تقلل من الكمية المتبقية
   ├─ الأرباح تتراكم في محفظة التاجر
   └─ تحديث الرصيد المتاح

3. الإغلاق (Closure)
   ├─ عند استنزاف جميع الكميات
   ├─ إغلاق رسمي للاستثمار
   └─ حالة: CLOSED
```

### 3. نظام المتجر الإلكتروني (E-Commerce Engine)

**الملفات**:
- `index.html` - الصفحة الرئيسية والمتجر
- `accounting_core.py` - معالجة المبيعات
- `backend_server.py` - API المتجر

**المسؤوليات**:
```
┌─ إدارة المنتجات ─────────────────┐
│ ├── تحميل المنتجات                │
│ ├── إدارة السعر والكمية            │
│ ├── تحديث المخزون                 │
│ └── عرض التفاصيل والصور           │
└──────────────────────────────────┘

┌─ سلة التسوق ─────────────────────┐
│ ├── إضافة منتجات                 │
│ ├── تحديث الكمية                  │
│ ├── حساب الخصومات                │
│ └── حساب الضريبة (15%)            │
└──────────────────────────────────┘

┌─ معالجة الطلبات ─────────────────┐
│ ├── تسجيل الطلب                   │
│ ├── توليد الفاتورة                │
│ ├── تحديث المخزون                 │
│ ├── حساب العمولة (5%)              │
│ └── تتبع الطلب                     │
└──────────────────────────────────┘
```

**تدفق عملية الشراء**:
```
العميل يختار منتج
    ↓
إضافة إلى السلة
    ↓
عرض ملخص السلة
    ├─ السعر الأساسي
    ├─ الخصم (إن وجد)
    ├─ الضريبة (15%)
    └─ الإجمالي النهائي
    ↓
تأكيد الطلب
    ↓
معالجة الدفع
    ↓
إنشاء فاتورة رسمية (INV-YYYY-NNN)
    ↓
تحديث:
├─ حساب المبيعات (debit)
├─ حساب العميل (credit)
├─ حساب العمولة (5%)
├─ حساب المخزون
└─ محفظة التاجر (إن كان استثماراً)
    ↓
إرسال إشعار بالطلب
    ↓
تتبع التوصيل
```

**الصيغة الحسابية**:
```
المجموع_قبل_الضريبة = Σ(سعر_الوحدة × الكمية)
الخصم = المجموع_قبل_الضريبة × نسبة_الخصم
الضريبة = (المجموع_قبل_الضريبة - الخصم) × 0.15
عمولة_المنصة = المجموع_قبل_الضريبة × 0.05
الإجمالي_النهائي = المجموع_قبل_الضريبة - الخصم + الضريبة
```

## 🗄️ هيكل قاعدة البيانات

### الجداول الرئيسية

```sql
-- جدول الحسابات
CREATE TABLE accounts (
    account_id VARCHAR(10) PRIMARY KEY,
    account_name VARCHAR(100),
    account_type VARCHAR(20),  -- asset, liability, equity, income, expense
    current_balance DECIMAL(12, 2),
    nature VARCHAR(5),  -- debit, credit
    created_at TIMESTAMP
);

-- جدول القيود المحاسبية
CREATE TABLE journal_entries (
    entry_id INTEGER PRIMARY KEY,
    description VARCHAR(255),
    entry_date DATE,
    total_debit DECIMAL(12, 2),
    total_credit DECIMAL(12, 2),
    created_at TIMESTAMP
);

-- جدول تفاصيل القيود
CREATE TABLE journal_details (
    detail_id INTEGER PRIMARY KEY,
    entry_id INTEGER,
    account_id VARCHAR(10),
    debit DECIMAL(12, 2),
    credit DECIMAL(12, 2),
    FOREIGN KEY (entry_id) REFERENCES journal_entries(entry_id),
    FOREIGN KEY (account_id) REFERENCES accounts(account_id)
);

-- جدول الاستثمارات
CREATE TABLE investments (
    investment_id INTEGER PRIMARY KEY,
    user_id VARCHAR(50),
    wallet_code VARCHAR(20),  -- حساب 116
    product_code VARCHAR(50),
    initial_quantity INTEGER,
    remaining_quantity INTEGER,
    unit_price DECIMAL(10, 2),
    total_amount DECIMAL(12, 2),
    profit_realized DECIMAL(12, 2),
    status VARCHAR(20),  -- ACTIVE, CLOSED
    created_at TIMESTAMP,
    closed_at TIMESTAMP
);

-- جدول المنتجات والمبيعات
CREATE TABLE orders (
    order_id INTEGER PRIMARY KEY,
    invoice_id VARCHAR(20),
    customer_id VARCHAR(50),
    product_code VARCHAR(50),
    quantity INTEGER,
    unit_price DECIMAL(10, 2),
    total_amount DECIMAL(12, 2),
    platform_fee DECIMAL(12, 2),  -- 5%
    status VARCHAR(20),  -- pending, delivered, cancelled
    created_at TIMESTAMP
);

-- جدول الفواتير
CREATE TABLE invoices (
    invoice_id VARCHAR(20) PRIMARY KEY,
    invoice_number VARCHAR(20),  -- INV-YYYY-NNN
    customer_name VARCHAR(100),
    customer_id VARCHAR(50),
    issue_date DATE,
    subtotal DECIMAL(12, 2),
    discount DECIMAL(12, 2),
    tax DECIMAL(12, 2),  -- 15%
    total DECIMAL(12, 2),
    status VARCHAR(20),
    created_at TIMESTAMP
);

-- جدول الموظفين
CREATE TABLE employees (
    employee_id INTEGER PRIMARY KEY,
    name VARCHAR(100),
    email VARCHAR(100),
    phone VARCHAR(20),
    position VARCHAR(50),
    salary DECIMAL(10, 2),
    hire_date DATE,
    status VARCHAR(20),  -- active, inactive
    created_at TIMESTAMP
);

-- جدول الحضور والانصراف
CREATE TABLE attendance (
    attendance_id INTEGER PRIMARY KEY,
    employee_id INTEGER,
    check_in TIMESTAMP,
    check_out TIMESTAMP,
    work_hours DECIMAL(5, 2),
    date DATE,
    FOREIGN KEY (employee_id) REFERENCES employees(employee_id)
);
```
